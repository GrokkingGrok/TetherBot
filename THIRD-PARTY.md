## Lucide

These clipboard icons are Lucide icons. Their strokes are converted to filled paths so GNOME can recolor them the same way as an Adwaita symbolic icon. The files are under `extension/icons/hicolor/scalable/actions/`.

- Name: Lucide
- Project: https://lucide.dev
- Source: https://github.com/lucide-icons/lucide
- License: ISC. `check` and `circle-help` are also derived from Feather, so the MIT notice below applies to those two.

| Icon | File | Page |
|---|---|---|
| tag | `tetherbot-tag-symbolic.svg` | https://lucide.dev/icons/tag |
| check | `tetherbot-check-symbolic.svg` | https://lucide.dev/icons/check |
| square-check | `tetherbot-square-check-symbolic.svg` | https://lucide.dev/icons/square-check |
| circle-help | `tetherbot-circle-help-symbolic.svg` | https://lucide.dev/icons/circle-question-mark |

`check` has no background. It is the check mark only. `circle-help` is the Lucide question-mark circle. The current file in the Lucide repo is `circle-question-mark.svg`. Lucide still publishes it as `circle-help`, and that name is an alias of the Feather icon `help-circle`.

The tag icon and the square-check icon are not in Lucide's list of icons derived from Feather, so the MIT notice does not apply to them.
